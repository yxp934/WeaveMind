# Schedule Generation Hardcoded Content Fix Report

**Date:** 2025-12-02
**Issue:** Schedule generation still uses hardcoded/fallback content
**Status:** ✅ FIXED AND DEPLOYED

---

## Problem Summary

The schedule generation system had multiple fallback mechanisms that would create generic, hardcoded content when AI parsing failed or when specific information wasn't extracted from the conversation. This resulted in:

1. Generic session topics like "Introduction", "Overview", "Basics"
2. Fallback session titles like "Session X: [Topic] - Additional Session X"
3. Generic overviews like "[Topic] - Session X"
4. Unhelpful placeholder content that wasn't course-specific

---

## Root Cause Analysis

### Location
- `/app/api/ai/generate-class-schedule/route.ts`
- `/app/api/ai/generate-schedule/route.ts`

### Issues Found

#### 1. **Hardcoded Topic Fallbacks** (Lines 222-224 in generate-class-schedule)
```typescript
// REMOVED - This was creating generic placeholders
while (sessionTopics.length < totalClasses && sessionTopics.length > 0) {
  sessionTopics.push(`${classTopic} - Additional Session ${sessionTopics.length + 1}`)
}
```

#### 2. **Hardcoded Overview Fallbacks** (Lines 333-338 in generate-class-schedule)
```typescript
// REMOVED - This was creating generic overviews
if (sessionOverviews.length === 0 && totalClasses > 0) {
  for (let i = 0; i < totalClasses; i++) {
    sessionOverviews.push(`${classTopic} - Session ${i + 1}`)
  }
}
```

#### 3. **Weak Topic Validation** (Lines 192-195 in generate-class-schedule)
```typescript
// IMPROVED - Added strict validation to reject generic terms
if (topic && topic.length > 3 && topic.length < 100 && !topic.match(/^(sessions?|classes?|hours?|minutes?|goals?|teaching)/i)) {
  sessionTopics.push(topic)
}
```

#### 4. **Poor AI Prompt** (Lines 105-123 in generate-schedule)
The original prompt was not comprehensive enough to prevent generic topics.

---

## Solution Implemented

### 1. **Removed All Hardcoded Fallbacks**

**Topic Fallbacks:**
- Completely removed code that created generic `${classTopic} - Additional Session X` topics
- System now relies entirely on AI to generate specific topics
- If topics cannot be extracted from conversation, AI will generate them

**Overview Fallbacks:**
- Completely removed code that created generic `${classTopic} - Session X` overviews
- System now gracefully handles missing overviews without creating placeholders
- AI uses class topic and context to build descriptions

### 2. **Enhanced AI Prompts**

**For `/api/ai/generate-class-schedule/route.ts`:**
```typescript
const sessionTopicPrompt = `You MUST generate exactly ${requirements.totalClasses} highly specific and meaningful session topics for a class on "${requirements.classTopic}".

**COMPREHENSIVE COURSE CONTEXT:**
- Class Topic: ${requirements.classTopic}
- Target Audience: ${requirements.targetAudience || 'Not specified'}
- Learning Goals: ${requirements.goals || requirements.objectives.join(', ') || 'Not specified'}
- Teaching Methodology: ${requirements.teachingMethod || 'Not specified'}
- Session Overviews: [extracted from conversation if available]

**CRITICAL REQUIREMENTS:**
- Return ONLY a JSON array of strings
- Each topic must be 5-7 words
- Topics MUST be specific to "${requirements.classTopic}"
- STRICTLY FORBIDDEN generic terms: "Introduction", "Overview", "Basics", "Fundamentals", "Part X", "Session X", "Class X", "Lesson X"

**QUALITY STANDARDS:**
- Topics must be progressive and build logically upon each other
- Each topic should focus on a distinct subtopic, skill, or concept
- Topics should be engaging, specific, and academically rigorous
- Avoid theoretical topics unless specifically requested

Generate exactly ${requirements.totalClasses} highly specific, progressive, and meaningful topics:`
```

**For `/api/ai/generate-schedule/route.ts`:**
Similar comprehensive prompt with additional validation criteria.

### 3. **Added Strict Validation**

```typescript
// Apply strict validation to prevent generic topics
if (!cleaned || cleaned.length < 5 || cleaned.length > 80) return null
const lowerTopic = cleaned.toLowerCase()

// Reject generic terms
if (lowerTopic.match(/^(introduction|overview|basic|introduction to|basics of|fundamentals|part|chapter|session|class|lesson|module|week|material|content)$/)) {
  return null
}

// Reject if it contains only generic words
if (lowerTopic.split(/\s+/).every(word => ['the', 'a', 'an', 'to', 'of', 'and', 'or', 'in', 'on', 'for', 'with', 'by', 'is', 'are', 'be', 'will', 'can', 'should'].includes(word))) {
  return null
}
```

### 4. **Improved Logging**

Added clear logging to distinguish between:
- Topics extracted from conversation
- Topics generated by AI
- Missing overviews (handled gracefully)

```typescript
if (sessionTopics.length === 0) {
  console.log('No session topics found in conversation - AI will generate topics')
} else if (sessionTopics.length < totalClasses) {
  console.log(`Only found ${sessionTopics.length} topics for ${totalClasses} sessions - AI will generate the rest`)
}
```
